# 国内期货品种卡

每个 YAML 文件是一张品种卡，文件名使用小写品种代码，例如 `rb.yaml`。品种卡服务于
研究、逐日状态机回测、风控和未来执行前人工核验；它不是 CTP 当前可交易合约映射。

## 静态与动态字段

`contract`、`delivery`、`roll` 与 `research` 记录相对稳定的规则和研究知识。`contract`
中的 `delivery_months` 是交易所挂牌交割月份的整数列表，不等于当日主力或当日可交易
合约；乘数、最小变动价位必须与 `configs/futures/cn_commodity_research.yaml` 一致。

`dynamic_snapshot` 列出的字段不可写死：交易时间、保证金、手续费、涨跌停、限仓、当前
主力和个人投资者临近交割限制都必须在每个交易日从交易所、期货公司或 CTP 查询取得，并
保存为带来源、交易日和抓取时间的数据快照。缺少快照时，回测或执行必须失败关闭。

## 换月

品种卡不猜测“当前主力”。实际回测使用具体 `instrument_id` 日线和显式换月表；执行使用
经人工核验的 `configs/instruments/ctp.yaml`。常见的持仓量、成交量和期限流动性仅能作为
人工或研究筛选依据，不能替代可审计的换月指令。
