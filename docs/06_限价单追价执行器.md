# 限价单追价执行器

本文件描述目标设计，不代表多轮追价执行器已经接入运行时。当前 settings 中保留追价
参数，但实盘主流程只进行单次订单路由；国内期货实际执行也尚未接入。

## 执行逻辑

计划实现完成后，执行逻辑应为：

1. 系统先根据最新参考价生成第一轮限价单。
2. 在单轮等待窗口内，系统轮询券商订单状态。
3. 若订单在该轮等待时间内未成交，则发起撤单。
4. 进入下一轮，按更积极的偏移重新生成限价单。
5. 达到最大追价轮数后：
   - 若 `NORTHSTAR_LIMIT_CHASE_FALLBACK_MODE=market`，则转市价单；
   - 若 `NORTHSTAR_LIMIT_CHASE_FALLBACK_MODE=cancel`，则最终撤单。

## 适用场景

- 已有的通用订单执行演练
- 对成交价格有一定控制要求
- 不希望一开始就全部直接用市价单

## 注意事项

这不是机构级算法执行器，不包含：

- VWAP / TWAP
- 动态盘口读取
- 智能拆单
- 微观结构优化

在完成状态持久化、撤单终态恢复、幂等重启测试和批次中止语义前，不应把本设计接入
真实账户。
