# 期货逐日状态机回测

`backtest.futures_daily` 用于验证国内期货的逐日持仓和撮合假设。它与连续合约权重收益
研究引擎完全分开，不能从 `storage/market/.../continuous.parquet` 直接读取。

## 必需输入

- `FuturesDailyBar`：每个实际合约每天一根 OHLC 日线。`instrument_id` 必须类似
  `rb2405`，不能是 `RB_CONT`。
- `FuturesInstrumentSpec`：实际合约的交易所、乘数、最小变动价位、初始保证金率、每手
  手续费和滑点 tick 数。参数必须来自可追溯的期货公司或交易所资料，不能沿用连续合约的
  临时假设。
- `FuturesTarget`：决策日的目标手数；正数为多头，负数为空头。默认在下一交易日开盘执行。
- `FuturesRollover`：明确指定哪一天从哪个具体合约平仓、转入哪个具体合约；不会自动猜测
  主力合约。
- `trading_calendar`：可选但建议传入的真实期货交易日列表。日线或换月日期不在日历中会失败。

## 日内成交规则

每个交易日按以下顺序执行：

1. 开盘按显式换月指令先平旧约、再开新约。
2. 执行延迟到期的策略目标，成交价为当日开盘价加方向性滑点。
3. 检查止损和止盈。止损被跳空越过时以开盘价成交；同日同时触及止损与止盈时，保守地按
   止损成交。
4. 按收盘价逐日盯市；若初始保证金要求超过权益，则按收盘价强平全部持仓。

手续费按每手扣减，滑点以 `tick_size * slippage_ticks` 计算。保证金不足的目标开仓会被
拒绝并记录在 `rejected_targets`，不会产生隐式杠杆。

## 当前边界

该引擎尚不等同于期货公司结算系统：未实现交易所逐品种手续费优惠、保证金日间调整、夜盘
交易时段、涨跌停可成交性、部分成交和资金利息。新增这些规则前必须先补充对应的具体合约
数据字段和可验证测试，不能用默认值猜测。
