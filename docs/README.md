## 文档维护规则

1. 新增功能先更新所属权威文档；不要为同一主题再创建“版本说明”或“增强说明”。
2. 命令以 `uv run northstar ...` 为准；任何会接触账户的命令必须同时说明当前安全门禁。
3. 当前事实、未来设计和历史记录必须分开表述。未来设计不能写成已可运行能力。
4. 本地 Markdown 链接必须可解析；文档契约测试会阻止失效的仓库内链接。
