# 研究准入政策与数据治理

> 候选配置版本：`cn_commodity_futures_research_conservative_v1`
> 当前状态：`pending_owner_approval`（默认失败关闭）
> 适用范围：国内商品期货的离线研究与候选策略人工评审
> 不适用范围：模拟交易授权、真实 CTP、真实资金或任何自动下单

本文件记录项目对数据供应商、授权边界、目标品种和候选策略研究门槛的默认决策，并说明
这些决策如何被配置和代码执行。它不是供应商合同，也不替代交易所、期货公司或法律意见。

## 1. 已固化的决策

### 1.1 数据供应商

首选采购候选为 **Wind WDS Server API / 数据库传输**，配置 ID 为
`wind_wds_server_v1`。选择原因是其官方资料明确面向企业量化研究、系统集成和内部嵌入，
数据库服务覆盖期货并支持模块/表级订阅。

- [Wind Server API](https://www.wind.com.cn/mobile/WDS/sapi/en.html)
- [Wind 数据库传输服务](https://www.wind.com.cn/portal/zh/WDS/database.html)
- [Wind 实时与历史行情服务](https://www.wind.com.cn/portal/zh/WDS/marketdata.html)

第二校验数据源候选为 `ifind_quant_api_v1`，采购比较候选为 `choice_quant_api_v1`。iFinD
官方量化接口说明覆盖期货、历史分钟线、实时行情和 Python/Linux 接口；Choice 仅作为采购
比较对象，不能因为存在接口说明而假定授权成立。

- [iFinD Quant API](https://quantapi.10jqka.com.cn/gwstatic/static/ds_web/quantapi-web/)
- [Choice](https://choice.eastmoney.com/)

所有三个商业条目当前均为 `procurement_pending`：项目没有购买服务、没有创建供应商账户、
没有保存凭据，也没有注册新的下载 adapter。`akshare_*` 和本地导入条目明确是
`research_only`，只可用于探索或工程验收，不能通过候选策略准入。

准入政策明确要求主数据源为 `wind_wds_server_v1`，并将 `ifind_quant_api_v1` 记录为独立
交叉验证的第二校验数据源；若未来改用其他供应商，必须变更并审查政策版本，不能只替换
adapter 名称。

### 1.2 授权边界

初始采购合同必须逐项书面确认以下用途后，才可将 Wind 条目激活：

| 类别 | 默认要求 |
| --- | --- |
| 允许用途 | 内部研究、历史回测、模型验证 |
| 供应商交叉验证 | Wind 为主源；iFinD 的独立逐日对账/交叉验证结论必须冻结 |
| 必须单独书面允许 | 内部服务器/云环境、无人值守同步、本地/衍生数据留存、分钟/Tick 数据 |
| 默认禁止 | 再分发、转售、公开原始数据、对外 API、第三方访问、模型训练、实时/实盘交易 |
| 凭据 | 仅保存环境变量名称；密钥、合同原件和账号绝不进入仓库 |
| 权威规则 | 交易所日历、会话、规则和公告优先；商业行情供应商不自动成为权威规则来源 |

上期所行情转发和交易所规则对用途、转接及商业使用均有独立限制；每个交易所、品种和
数据集必须保留对应的合同/公告引用。尤其是 INE 原油不得因为上期所体系相近而自动继承
授权。官方规则与日历来源应按交易所版本化保存：

- [上期所](https://www.shfe.com.cn/)、[大商所](https://www.dce.com.cn/)、
  [郑商所](https://www.czce.com.cn/)、[广期所交易日历](https://www.gfex.com.cn/gfex/jyrl/list.shtml)、
  [上海国际能源交易中心](https://www.ine.cn/)。这些入口仅用于定位公告；真正的授权、
  日历和规则证据必须保存具体公告的版本、有效日和内容哈希，不能只引用首页。

### 1.3 目标品种

候选策略的核心研究宇宙为 `cn_commodity_futures_research_core_v1`：

| 层级 | 品种 | 交易所 | 说明 |
| --- | --- | --- | --- |
| core | RB 螺纹钢 | SHFE | 成熟黑色系代表 |
| core | CU 铜 | SHFE | 有色金属代表 |
| core | I 铁矿石 | DCE | 黑色原料链代表 |
| core | M 豆粕 | DCE | 农产品代表 |
| core | TA PTA | CZCE | 化工代表 |
| extension | SA 纯碱 | CZCE | 达到同样历史/规则门槛后才可纳入 |
| extension | SC 原油 | INE | 必须独立完成 INE 授权、规则与日历核验 |
| extension | SI 工业硅 | GFEX | 历史长度和流动性证据达标前不可参与准入统计 |

核心五品种必须 **完整覆盖**，不能用 extension 或连续合约替代。当前公开实际合约工程
样本只含 `RB/CU/TA/SA/SC`，与核心宇宙不同，因而必然不能通过本政策；这是预期的安全
结论，不是降低门槛的理由。

## 2. 保守候选研究阈值

完整参数在
[`configs/research/admission/cn_commodity_futures_research_conservative_v1.yaml`](../configs/research/admission/cn_commodity_futures_research_conservative_v1.yaml)。

| 类别 | 默认门槛 |
| --- | --- |
| 数据历史 | 至少 8 年完整实际合约历史，目标 10 年，至少 2,016 个历史 session |
| 数据完整性 | 权威交易日历、完整夜/日盘、权威动态规则；未知缺失 session 和未解决官方差异均为 0 |
| 样本外 | 至少 3 年、720 个交易日；至少 3 个 walk-forward 折且全部净正 |
| 交易归因 | 至少 60 个已闭合 OOS round-trip；fill event 不能替代闭合交易 |
| 绩效风险 | 净 Sharpe ≥ 0.5；OOS 最大回撤 ≤ 20% |
| 资金风险 | 最大保证金/权益 ≤ 50%；最低可用资金/权益 ≥ 50%；不允许保证金追缴或强平 |
| 压力测试 | 成本倍数 1.0×、1.5×、2.0× 全部通过 |
| 稳健性 | 至少 8 个参数邻居、通过比例 ≥ 60%，并有不可变实验台账 |

这些数值是保守的项目治理默认值，不是收益预测、交易所规则或普适最优参数。`PASS` 的
唯一含义是“可进入具名人工研究评审”；它不会改变 `futures.execution_allowed`、
`NORTHSTAR_LIVE_TRADING_ENABLED`、broker 设置或任何订单路径。

## 3. 配置与运行链路

```text
configs/data/sources.yaml
    └─ 数据源、adapter、许可证据字段、用途边界
configs/instruments/universes/*.yaml
    └─ 画像品种池与候选核心/扩展品种
configs/research/admission/*.yaml
    └─ 数据、样本、风险、压力和稳健性阈值
交易画像 data.source_id + research_admission.policy_id
    └─ 数据 manifest v3 冻结来源/品种池/政策 SHA-256
回测 runner
    └─ analytics、report.json、manifest.json、Markdown/PDF 中写入准入结论
```

查看当前配置而不访问供应商：

```powershell
uv run northstar data sources
uv run northstar data profiles
```

运行实际合约工程回测并查看准入结论：

```powershell
uv run northstar backtest run portfolio --profile cn_futures_daily_actual_offline
uv run northstar research assess portfolio --profile cn_futures_daily_actual_offline
```

`--require-pass` 适合未来人工审批或 CI 门禁；当前公开短样本会以状态码 `2` 退出，这是
正确结果：

```powershell
uv run northstar research assess portfolio --profile cn_futures_daily_actual_offline --require-pass
```

普通 `backtest run` **不会**因准入不通过而拒绝生成报告。报告中的“研究准入结论”会显示
`PASS`、`NOT_ELIGIBLE`、`INSUFFICIENT_EVIDENCE`、`NOT_APPLICABLE` 或
`NOT_CONFIGURED`，并逐项列出实际值、阈值和证据缺口。

## 4. 数据制品与变更规则

数据 manifest 已升级为 `data_manifest_v3`，冻结：

- `source_id`、技术 adapter、来源配置 SHA-256 和许可证状态；
- `universe_id` 与品种池配置 SHA-256；
- 准入政策 ID 与政策配置 SHA-256；
- 导入方式（仅文件名，不写绝对路径）、数据内容 SHA-256 和 schema 质量结果。

画像或上述任何治理配置变更后，旧数据制品会被拒绝读取，必须重新下载或重新导入。实际
合约日线/分钟数据还会拒绝出现不属于画像品种池的产品；小样本可以是品种池子集，但只能
由准入评估判定为覆盖不足，不能误报为完整研究样本。

## 5. 激活商业数据源的人工步骤

在没有项目所有者明确批准前，AI 和代码都不得执行以下操作。得到合同后，由具名负责人：

1. 在 `configs/data/sources.yaml` 的对应条目中填写**脱敏**合同引用、有效期、已授权交易所、
   品种、数据集、频率和运行环境；合同原件保存在受控的仓库外位置。
2. 仅在合同明确允许后填写 `permitted_purposes`、留存期和内部存储/衍生数据开关；不要凭
   产品宣传页推断许可范围。
3. 实现并审查独立的供应商 adapter，使用环境变量引用凭据；不得复用 AKShare adapter 或
   通过 `--provider` 绕过画像绑定。
4. 导入/下载权威日历、会话、实际合约链和规则快照，完成逐日对账后才将 source/policy
   状态从 `procurement_pending`/`pending_owner_approval` 改为 `active`。
5. 运行多年实际合约、walk-forward、压力测试与实验台账；即使结果为 `PASS`，仍须通过
   独立 simulated、CTP 和实盘阶段门禁。

本政策与项目总路线图共同适用，后续阶段见
[项目主规划与实施状态](15_项目主规划与实施状态.md)。
