# 架构审核与演进路线

## 当前结论

项目已收敛为国内中低频期货研究系统：唯一内置画像使用连续合约，策略输出只用于
离线研究。股票、ETF、旧数据源、旧策略、旧回测器和旧券商适配器均不再保留。

当前已具备的可靠性基础包括订单幂等持久化、账户级执行租约、订单终态恢复、成交归因
和运行健康记录。持仓已使用可表达空仓的批次头，并按 broker/account/profile 隔离；
数据制品也会校验内容哈希。这些机制仍不等于具备真实期货交易能力。

## 已实现的 CTP 合约边界

`configs/instruments/ctp.yaml` 是连续研究 symbol 到具体 CTP 合约的唯一映射来源。
映射按 `continuous_symbol`、`data_symbol`、`instrument_id`、`exchange_id`、品种、
乘数和最小变动价位进行严格校验；重复或禁用映射会失败关闭。

订单计划在非连续合约画像中会先校验该映射，但 CTP 订单适配器尚未实现，因此仍会
明确拒绝继续执行。

## 下一阶段

1. 接入可信的国内期货历史数据与主力换月规则，并保留原始数据与换月元数据。
2. 逐日盯市、保证金、手续费、保护价和显式换月状态机已经存在；下一步补充夜盘、
   平今/平昨、交易所动态保证金和更完整的合约到期规则。
3. 单独实现 `CTPBrokerAdapter`：认证、结算确认、报单、撤单、成交/持仓/资金查询。
4. 在仿真环境完成断网、重启、重复回报、部分成交、平今平昨和换月演练。
5. 通过数据、风控、对账与人工审批后，才考虑创建真实 `*_live` 画像。
