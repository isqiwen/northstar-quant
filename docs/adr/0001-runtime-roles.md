# 三个自带 Web 的应用，共享业务实现

当前决策（2026-09-08）：选择单仓库中的 Data、Research、Live 三个独立交付应用，
替代此前要求中央 Console 的四角色目标；管理入口随被管理应用部署，Live 不依赖家庭网络。
各应用可含多个进程：Live Web 与交易内核独立监管，Research 执行器和长期采集器不属于页面生命周期。
代价是分别管理应用权限、部署与恢复；复用业务和呈现组件、交换固定产物，避免重复实现或集中生命周期。
Research 按实测内存、磁盘和负载调度并尽量使用硬件，不以任意固定限核作为架构。

只维护当前实现和协议，不保留旧 Console 兼容入口；历史运行证据不是兼容承诺。
先复用 #39 的内核隔离成果，在 #40 交付 Live 自有入口，再推进受控仿真，不等待完整数据或研究平台。
当前实现与目标的差异见 [架构](../ARCHITECTURE.md)，验收与顺序见 [开发计划](../ROADMAP.md)。
